# Vigil App

A simple Node.js Express application used as the target codebase for the **Vigil – Living Architectural Immune System** project (IBM Bob 2.0 Hackathon).

## Purpose
This repository intentionally contains:
- Outdated / vulnerable dependency patterns
- Some AI-generated style code risks
- Clear architectural invariants that can be violated

Vigil will monitor this repo for dependency drift, AI-code risks, and architectural invariant violations.
